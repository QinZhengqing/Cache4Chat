# 简介与安装

## 这是什么

Cache4Chat 是一个基于`酒馆助手/@JS-Slash-Runner`运行的 SillyTavern 脚本。
它让你可以**直接在提示词里声明缓存断点**，从而对接 Anthropic API 格式的 Prompt Caching
（`cache_control`），无需修改 SillyTavern 的服务器配置文件。

## 安装

1. 运行 `npm install && npm run build`，得到 `dist/bundle.js`；
2. 在酒馆助手（JS-Slash-Runner）中新建脚本，粘贴 `dist/bundle.js` 的内容并启用；
3. 控制台出现 `[Cache4Chat] v1.0.0 loaded` 即加载成功。

## 适用范围

| API 来源                         | 是否支持 | 说明                                                                         |
| -------------------------------- | -------- | ---------------------------------------------------------------------------- |
| Custom（OpenAI 兼容端点 / 反代） | ✅       | SillyTavern 后端原样透传 messages                                            |
| OpenRouter                       | ✅       | 原生支持消息级 `cache_control`                                               |
| Claude 直连源                    | ❌       | ST 后端转换器会丢弃自定义键，请改用 `config.yaml` 的 `claude.cachingAtDepth` |

注意：Custom 源若开启了 **Prompt Post-Processing**（提示词后处理），消息会被后端
压平重建，`cache_control` 键会丢失。使用本脚本时请保持该选项为 None。
